# Calendar API

Spring Boot-приложение для формирования календаря указанного года на основе одного из 14 возможных шаблонов

## Сколько всего уникальных календарей существует вне зависимости от номера года

Всего существует **14 уникальных вариантов календарного года**

Календарь определяется двумя признаками:

- день недели, на который приходится 1 января: 7 вариантов
- тип года: обычный или високосный

## Описание проекта
Приложение получает номер года, определяет:

* день недели, на который приходится 1 января
* является ли год високосным

После этого приложение получает подходящий шаблон из PostgreSQL и формирует календарь выбранного года

## Возможности

Приложение позволяет:

* получить календарь выбранного года
* получить отдельный месяц
* получить отдельный день
* получить список всех 14 шаблонов
* определить день недели для каждого дня месяца
* получить русские названия месяцев и дней недели
* проверить корректность года, месяца и дня
* получить структурированный JSON при возникновении ошибки
* просматривать и тестировать API через Swagger

## Ответственность слоёв

### Controller

Принимает HTTP-запросы, проверяет параметры и вызывает сервисный слой

```text
CalendarController
```

### Service

Содержит основную бизнес-логику:

* проверяет год, месяц и день
* определяет день недели первого января
* определяет високосность года
* формирует ключ шаблона
* получает нужный шаблон из хранилища

```text
CalendarServiceImpl
```

### Factory

Создаёт календарные шаблоны

Для каждого шаблона фабрика формирует:

* 12 месяцев
* необходимое количество дней
* день недели для каждого дня

```text
CalendarFactoryImpl
```

### Storage

Предоставляет сервису доступ к шаблонам календаря

```text
CalendarTemplateStorage
JpaCalendarTemplateStorage
```

### Repository

Работает с PostgreSQL через Spring Data JPA

```text
CalendarTemplateRepository
```

## Структура базы данных

В PostgreSQL создаются три таблицы:

```text
calendar_templates
calendar_months
calendar_days
```

### calendar_templates

Хранит 14 шаблонов календарного года

Основные поля:

```text
id
first_day_of_year
leap_year
```

### calendar_months

Хранит месяцы каждого шаблона

Основные поля:

```text
id
month_number
template_id
```

### calendar_days

Хранит дни каждого месяца

Основные поля:

```text
id
day_of_month
day_of_week
month_id
```

Связи:

```text
calendar_templates 1 → * calendar_months
calendar_months    1 → * calendar_days
```

В базе хранится:

```text
14 шаблонов
168 месяцев
5117 дней
```

## Инициализация шаблонов

При первом запуске приложение проверяет наличие шаблонов в базе данных

При следующих запусках шаблоны повторно не создаются

## REST API

### Получить календарь года

```http
GET /calendars/{year}
```

### Получить календарный месяц

```http
GET /calendars/{year}/months/{monthNumber}
```

### Получить календарный день

```http
GET /calendars/{year}/months/{monthNumber}/days/{dayNumber}
```

### Получить все шаблоны

```http
GET /calendars/templates
```
